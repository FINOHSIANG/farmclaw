# 四时导航规则

## IA Thesis

以任务为第一入口，以对象为上下文，以 AI 为横向协作者；地图不承担所有导航职责。

## Global Navigation

| Label | Destination | Who sees it | Why it is top-level |
| --- | --- | --- | --- |
| 今日 | 四时早报、风险、待审批和当天作业 | 全部登录用户 | 高频入口，回答“现在先做什么” |
| 农场 | 地图、地块、温室、批次和设备 | 全部登录用户，按范围过滤 | 农业对象的稳定入口 |
| 作业 | 农事计划、任务、工单和巡检 | 生产、农艺、值守、巡检 | 把建议变成可执行工作 |
| 智能 | 会话、建议、审批、技能、知识、审计 | 全部用户，按权限显示动作 | 体现四时 Agent 的核心能力 |
| 台账 | 投入品、采收、质量、成本、追溯、报告 | 生产、管理、认证相关角色 | 形成可信结果和合规证据 |
| 系统管理 | 成员、设备、数据源、权限、通知 | 管理员和运维 | 低频高风险能力，避免干扰日常作业 |

## Local Navigation

- 今日：使用任务队列和状态筛选，不再嵌套多层菜单。
- 农场：地块/温室列表使用侧栏；对象详情使用 4–6 个页签：概览、趋势、作业、设备、预警、台账。
- 作业：日历、列表、地图三种视图；任务详情使用线性步骤：计划 → 执行 → 复核 → 关闭。
- 智能：会话、建议、审批、知识、审计使用页签；建议详情用右侧上下文栏展示依据和执行边界。
- 台账：批次详情使用时间线；报表和认证材料使用列表与筛选。
- 系统管理：侧栏按范围分为农场、成员、设备、数据源、策略、通知。

## Contextual Navigation

- 主要动作贴近当前对象：地块详情提供“生成今日计划”“新建任务”“查看批次台账”。
- 高风险动作必须在动作前展示对象、影响范围、参数、操作者和有效期。
- 详情页始终提供“返回列表”和“相关任务/预警/记录”。
- 地图弹窗只做摘要，点击后进入可分享的对象详情页。

## Wayfinding

- 页面标题必须与导航标签一致。
- 详情页使用面包屑：农场 / 地块 / 批次 / 当前页面。
- 当前范围、数据时间和数据来源固定显示在页面标题区。
- URL 使用可读对象名和稳定 ID，例如 `/farms/{farmId}/fields/{fieldId}`。
- 任务、告警和批次可通过 URL 直接打开，刷新后恢复筛选和上下文。

## Permissions and Roles

| Role | Default landing | Can view | Can change |
| --- | --- | --- | --- |
| 值守人员 | 今日 | 当前农场、告警、任务 | 确认告警、接单、反馈，不可改策略 |
| 生产负责人 | 今日 | 所属农场全量生产数据 | 派单、审批生产建议、改计划 |
| 农艺师 | 智能 | 批次、趋势、知识与建议 | 修改建议、标注诊断、提交复核 |
| 巡检人员 | 作业 | 分派给自己的任务 | 上传照片、定位、填写结果 |
| 运维人员 | 系统管理 | 设备、网关、数据源 | 维护设备、重试接入，不可审批生产动作 |
| 管理员 | 今日 | 所有授权范围 | 成员、权限、策略和审计导出 |
| 只读访客 | 今日 | 脱敏总览和报告 | 无写权限 |

无权限状态应说明“需要哪种角色、由谁申请”，不能只隐藏入口后让用户猜测。
