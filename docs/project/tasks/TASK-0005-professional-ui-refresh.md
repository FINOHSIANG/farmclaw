# TASK-0005 专业科技控制台 UI/UX 更新

创建日期：2026-08-25
状态：已完成

## 目标

- 将现有数字孪生大屏更新为更专业、克制、科技化的农业运营控制台。
- 提升信息层级、地图可视面积、状态可读性、交互反馈和移动端操作效率。

## 范围

- 全局视觉令牌与产品/设计规范。
- 顶部系统栏、遥测、事件、专题导航和 AI 指令栏。
- AI 托管与安防面板的一致组件语言。
- 桌面及 390×900 移动端响应式布局与键盘焦点。

## 非目标

- 不改变 AI 托管、安防、地图和 Gateway 的业务语义。
- 不引入外部付费字体、图标或新的地图服务。

## 验收标准

- 视觉风格专业科技化，主强调色使用克制，状态含文字/颜色双重提示。
- 地图、面板、专题工具带和指令栏无明显遮挡。
- 桌面与移动端主要操作可触达，导航不再竖排。
- 构建、AI、安防和 Python 回归测试通过；真实浏览器无运行错误。

## 风险与回滚

- 风险：密集控制台在小屏可能裁切；通过结构性断点和浏览器验证控制。
- 回滚：移除主题令牌并恢复三个面板组件的上一版样式，不影响业务状态机。
