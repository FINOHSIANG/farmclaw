# TASK-0012 设施图标差异化

创建日期：2026-08-25
状态：已完成

## 目标

- 让地图设施和运营设备通过形状即可识别类别，不再全部使用相同圆点或状态点。
- 类别图标与运行/告警状态分离，继续以文字和状态色共同表达状态。

## 范围

- 园区设施点：仓储、服务站、检测中心三类，共 6 点。
- 安防摄像头：使用统一摄像头形状，外围 halo 继续表达状态。
- 运营设备目录：泵阀、环境控制、施肥、水产、传感器五类图标。
- MapLibre 图标、弹窗类型、点击选择、移动端、纯函数测试和相关回归。
- AMap 服务设施使用同一套代码内 SVG；没有 Key 时只做静态/构建验证，不宣称完成在线 AMap 安防验证。

## 非目标

- 不给缺少用途属性的 171 个建筑和 18 个温室面域虚构类别。
- 不把没有坐标的运营设备投放到地图。
- 不用类别图标颜色代替运行中、待机、预警、离线等状态。

## 验收标准

- `serverpoi.geojson` 6 点显式分类且计数仓储 3、服务 2、检测 1。
- 图标映射完整，未知类型安全回退；SVG 无外链、脚本或事件处理器。
- MapLibre 设施与摄像头形状可辨，图标/标签同步显隐，点击弹窗和选择环正常。
- 运营设备 8 条均能显示有效类别图标，状态点和文字仍保留。
- 1440×900 与 390×900 可读，控制台 0 error/warning；现有地图、安防、运营、AI、产值与构建不回归。

## 风险与回滚

- 风险：图标资源未注册而被透明兜底吞掉；图标过密；AMap 多层显隐冲突；名称推断漂移。
- 回滚：恢复服务点 circle/统一 PNG，移除摄像头 glyph、设备类别图标与分类字段。
