# TASK-0008 运营看板：资源消耗与设备运转

创建日期：2026-08-25
状态：已完成

## 目标

- 新增资源消耗看板，快速判断水、电、肥液的周期消耗、目标偏差与区域分布。
- 新增设施设备运转看板，快速识别运行、待机、注意和离线设备。
- 明确区分网关实时观测和演示基线，不将静态数据误报为真实设备状态。

## 范围

- 共享“运营看板”业务专题，内部切换“资源消耗 / 设备运转”。
- 资源看板支持今日、本周、本月三个周期，包含当前值、目标、偏差、趋势和区域占比。
- 设备看板包含状态汇总、按状态筛选、设备负载、累计运行时长和最近信号。
- 平台数据源标签、桌面/移动布局、测试、文档与独立复核。

## 非目标

- 不伪造真实智能电表、水表、肥液流量计或 PLC 数据。
- 不执行设备启停、调参或远程维护动作。
- 不新增后端数据库或外部能源计量接口。

## 验收标准

- 两个看板均能从业务专题入口进入，桌面和 390×900 移动端可操作。
- 三个资源周期的单位、目标、当前值、趋势和分区数据守恒。
- 设备状态汇总与设备列表守恒，筛选结果与计数一致。
- 界面始终显示“网关观测”或“演示基线”数据源，不混淆真实与演示。
- 产值、地图标注、AI、安防、Python 流程和构建不回归。

## 风险与回滚

- 风险：业务导航过长、演示数据语义误解、移动端可视区遮挡。
- 回滚：移除运营看板入口、组件与纯函数模型，恢复原四专题导航。
