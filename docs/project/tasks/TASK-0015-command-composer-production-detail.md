# TASK-0015 对话编辑器与生产态势详情

创建日期：2026-08-26
状态：已完成

## 目标

- 底部 AI 指令栏支持本地 Agent 选择和文件/图片附件本地预览。
- 生产态势展示作物、批次、阶段进度、区域和环境检查详情。

## 范围

- `FarmclawHud.vue` 指令编辑器和生产态势面板。
- `useFarmclawBridge.js` 结构化聊天元数据向后兼容。
- `index.vue` 结构化命令适配。
- 静态校验、文档和桌面/移动端回归。

## 非目标

- 不伪造真实 Agent 后端切换；当前 Agent 为本地路由选择。
- 不伪造文件上传成功；附件仅本地预览，聊天只携带 `uploaded:false` 元数据。
- 不把生产档案和健康阈值描述为真实产量或现场控制结果。

## 验收标准

- 3 个本地 Agent 可切换，发送事件带 Agent 标识。
- 图片可本地预览，文件显示名称和大小，支持移除和 object URL 清理。
- 限制 5 个附件、单文件 10 MB，并过滤允许类型。
- 生产态势展示批次、作物、阶段、进度、5 项遥测检查和健康摘要。
- 桌面/390×900 无溢出，现有地图、AI、安防、运营和事件收起不回归。

## 风险与回滚

- 风险：浏览器本地预览与实际后端上传边界被误解；移动端底部编辑器空间不足。
- 回滚：移除结构化命令、附件本地状态和生产详情区，恢复纯文本命令与基础遥测卡片。
