# TASK-0007 地图标注优化

创建日期：2026-08-25
状态：已完成

## 目标

- 让生产、安防和产值专题中的业务对象可以直接识别，不再只依赖颜色和点形。
- 通过分级缩放、碰撞避让、状态文字和语义颜色提升专业可读性。

## 范围

- MapLibre 模式中的作物/水产品类、产值预测品类、仓储/服务点、电子围栏与摄像头标注。
- 标注密度、字号、暗色地图对比度、缩放阈值和专题显隐联动。
- 桌面 1440×900 与移动 390×900 真实渲染验证。

## 非目标

- 不修改原始 GeoJSON 业务数据。
- 不增加需要 API Key 的地图或地理编码服务。
- 不改写 AMap/Loca 兼容实现。

## 验收标准

- 生产专题能识别主要作物和水产品类，不将数百个原始点全量标字。
- 安防专题标注同时显示名称与状态，告警/离线/维护不只依赖颜色。
- 产值专题显示品类、预测指数和点数，面板筛选会同步过滤标注。
- 标注具有暗色底图可读对比度、碰撞避让和缩放分级；桌面/移动无大面积遮挡。
- 现有产值、AI、安防测试和前端构建通过。

## 风险与回滚

- 风险：MapLibre 样式表达式错误、标注冲突过多、不同缩放级字号失衡。
- 回滚：移除新增标注 source/layer 及逻辑图层映射，恢复原 camera label 样式。
