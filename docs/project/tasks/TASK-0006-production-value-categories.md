# TASK-0006 产值预测分类展示

创建日期：2026-08-25
状态：已完成

## 目标

- 让产值预测按产业与品类分类显示，并与地图预测点联动。
- 明确区分预测指数和真实财务收入，避免误导。

## 范围

- 从预测点、作物点和水产点构建确定性的分类模型。
- 支持全部、种植业、水产养殖和具体品类筛选。
- 展示综合指数、高潜力点、品类占比和相对基准表现。
- 桌面与移动端分类分析面板、地图过滤和测试。

## 非目标

- 不生成真实销售额、价格、成本或利润数据。
- 不接入外部市场行情接口。

## 验收标准

- 分类汇总总数与原始预测点一致，品类筛选结果稳定。
- 切换产业/品类后列表和地图预测点同步变化。
- 界面明确标记为演示预测指数，不代表财务收入。
- 现有 AI、安防、构建和 Python 流程不回归。

## 回滚方案

- 移除分类模型、产值面板和地图 filter，恢复原 value 专题图层。
