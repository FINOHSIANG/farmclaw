# TASK-0016 农药资源与虫害预警

创建日期：2026-08-26
状态：已完成

## 目标

- 运营保障资源看板增加农药消耗与分区明细。
- 生产态势增加按田块展示的虫害预警卡片。

## 非目标

- 不伪装真实农药计量、库存或现场植保告警。
- 不把演示虫害预警并入基于遥测快照的生产健康结论。

## 验收标准

- 日/周/月资源模型包含农药单位、汇总、趋势和分区守恒。
- 桌面与 390×900 移动端可见农药卡片且无水平溢出。
- 生产态势显示虫害名称、风险级别、置信度、影响范围、依据和建议，并标注演示来源。
- 静态校验、Playwright 回归和构建通过。

## 风险与回滚

- 风险：演示预警被误解为真实识别结果。
- 回滚：移除 pesticide 资源字段和 pestWarning 展示区，恢复原资源卡及生产详情。
