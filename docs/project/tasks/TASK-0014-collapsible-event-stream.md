# TASK-0014 系统事件面板可收起

创建日期：2026-08-26
状态：已完成

## 目标

- 系统事件面板支持手动收起和展开，减少对地图的遮挡。
- 收起后保留 EVENT STREAM、系统事件名称、实时事件数量和明确的展开按钮。

## 范围

- `FarmclawHud.vue` 增加本地收起状态、可访问按钮和紧凑样式。
- 事件数据继续接收和累计；收起只改变显示，不改变网关或事件模型。
- 增加静态校验并验证桌面与移动端布局。

## 非目标

- 不持久化用户收起偏好。
- 不修改事件数量上限、事件排序或网关协议。
- 不在当前隐藏事件面板的窄屏断点强制显示它。

## 验收标准

- 桌面点击“收起系统事件”后列表消失，标题与数量保留，按钮变为“展开系统事件”。
- 再次点击可恢复列表，状态语义通过 `aria-expanded` 暴露。
- 收起后地图工具和底部导航无重叠；控制台无 error/warning。
- 现有地图、安防、运营、AI、产值与构建无回归。

## 风险与回滚

- 风险：面板高度切换造成布局闪动或按钮触控面积不足。
- 回滚：移除 `eventsCollapsed`、切换按钮和 collapsed 样式，恢复固定事件列表。

## 验证结论

- 展开、收起、再次展开和移动端回归通过；独立复核未发现阻断问题。
