# TASK-0003 电子围栏与摄像头点位

创建日期：2026-08-25
状态：已完成

## 目标

- 在免费地图安全专题中增加电子围栏分区和摄像头点位。
- 支持围栏布防/撤防、告警确认、摄像头显示切换、点位聚焦和详情查看。
- 将安防操作写入 Farmclaw HUD 事件流。

## 非目标

- 本阶段不接入真实 RTSP/GB28181 视频流、录像存储或生产门禁设备。
- 不实现用户鉴权、生产告警推送或持久化配置。
- AMap provider 仅保留原有安全图层，不在本阶段复制完整新安防交互。

## 数据与范围

- 新增 `security.geojson`，使用统一 Feature 属性区分 `fence` 和 `camera`。
- 电子围栏至少覆盖园区周界、核心温室、仓储和水岸区域。
- 摄像头包含在线、离线、维护和告警状态，以及名称、区域、方向、最近在线时间等展示字段。

## 实施计划

1. 建立安防 GeoJSON 数据和 MapLibre 图层。
2. 增加图层点击、摄像头聚焦、围栏状态更新和告警确认 API。
3. 新增安防面板并与安全专题、事件流联动。
4. 验证桌面/移动端、布撤防、点位详情、告警和图层切换。

## 验证计划

- `npm run build`
- Playwright：切换安全巡防、摄像头点位点击、围栏布撤防、告警确认、移动端。
- `python tests/test_flow.py`
- 独立 verifier 检查数据模型、地图状态和回归。

## 回滚方案

- 删除 security source/layers、SecurityPanel 和相关 adapter API，即可恢复现有免费地图功能。

## 风险

- 当前点位和围栏为演示数据，投产前必须以现场测绘、设备台账和权限策略替换。
- “摄像头画面”仅为状态预览，不应误认为真实视频流。

## 验证结论

- 独立 verifier：PASS，无 P0/P1/P2 问题。
- 数据校验、生产构建、Python 回归、桌面与移动端交互均通过。
- Verifier 建议的数据坐标范围、围栏闭合、direction/fov/level 字段校验已补强。
