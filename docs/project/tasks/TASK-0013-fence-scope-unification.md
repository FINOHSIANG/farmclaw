# TASK-0013 电子围栏与园区范围统一

创建日期：2026-08-26
状态：已完成

## 目标

- 以 `border.geojson` 的园区实测边界作为“园区周界”电子围栏的唯一范围基准。
- 统一地图、安防面板和弹窗中的防区范围口径，避免矩形周界与真实园区边界错位。

## 范围

- 将 `FENCE-PERIMETER` 的 MultiPolygon 几何与 `border.geojson` 完全一致。
- 安全专题只使用电子围栏线表达安防边界，避免与独立园区边界线重复叠加。
- 围栏列表展示所属防区，围栏弹窗统一显示“防区范围”。
- 增加数据一致性校验、桌面/移动端及交互回归。

## 非目标

- 仓储、水岸两个内部防区继续保持演示范围；核心温室围栏改为绑定现有温室面域，移除穿越检测中心的旧矩形蓝线。
- 不将电子围栏描述为现场测绘或真实门禁策略。
- 不扩展 AMap 安防能力；AMap 继续保留既有实现边界。

## 验收标准

- 园区周界电子围栏与 `border.geojson` 的 geometry 深度一致，核心温室围栏与 `greenhouse.geojson` 的 18 个温室面域一致。
- 安全专题不同时渲染独立 border line 与周界 fence line。
- 围栏列表、预览和弹窗能看到一致的防区名称。
- 聚焦园区周界、隐藏/显示围栏、布撤防在桌面和移动端正常。
- 安防、地图标注、设施图标、构建和 Python 流程无回归。

## 风险与回滚

- 风险：MultiPolygon 展平、聚焦或标签中心计算错误；隐藏围栏后安全专题不再显示周界。
- 回滚：恢复 `FENCE-PERIMETER` 原矩形 Polygon、security TOPICS 的 `borderLayer` 和原面板文案。

## 验证结论

- 独立 verifier：PASS，无阻断问题。
- 园区周界与 border geometry 深度一致；核心温室与 18 个 greenhouse 面域深度一致。
- 检测中心附近旧青蓝矩形已消失；桌面、390×900、显隐、聚焦、弹窗和全量回归通过。
