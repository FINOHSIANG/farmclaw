# 农机监测与数字孪生地图联动

日期：2026-09-02
范围：`farmclaw-dashboard` 前端与四时汇报材料
状态：已完成

## 需求

在运营保障专题增加农机监测板块，展示农机运转情况，并让农机状态与数字孪生地图保持一致。

## 交付

- 新增独立农机监测模型：7 台演示农机，覆盖作业中、待机、充电中、异常、离线五类状态。
- 面板展示任务、进度、速度、油量/电量、今日与累计工时、作业模式、区域、操作员、最近信号、维护计划和异常说明。
- MapLibre 新增独立 `machinery` GeoJSON source、状态光晕、方向图标、遥测新鲜度角标和缩放分级标签。
- 面板卡片 → 地图定位 → 运行孪生弹窗，以及地图点选 → 面板高亮双向联动已接通。
- 状态筛选同步作用于清单和地图；无坐标或越界坐标不会进入地图图层。
- 高德地图路径不伪造农机定位，操作时给出明确暂不支持提示。
- 汇报稿、地图视觉升级文档、项目 README 已同步更新。

## 数据边界

- 当前农机数据来源为 `demo-machinery` / 演示农机遥测，不代表真实车辆位置、运行状态或控制结果。
- 网关在线状态与农机运行状态分开表达；后续真实接入建议使用 WGS84、稳定 `machine_id` 和 `observed_at`。
- 本轮只提供查看、筛选、定位和最近遥测，不提供远程启停、自动调度、轨迹回放或维修工单。
