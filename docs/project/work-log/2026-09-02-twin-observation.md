# 数字孪生对象预警与摄像头观测

日期：2026-09-02
范围：`farmclaw-dashboard` 地图对象弹窗、Farmclaw observer 消息桥接
状态：已完成

## 需求

用户要求数字孪生对象弹窗能够同时显示预警信息和实时摄像头结果，参考水产塘口对象弹窗截图。

## 交付

- 新增 `src/utils/twinObservation.js`，统一对象级预警、摄像头状态、媒体地址、识别结果、置信度和观测时间模型。
- `freeMap.js` 的空间对象弹窗增加“对象预警”和“摄像头观测”分区；没有媒体地址时用可读的状态取景框承载识别结果，并明确演示、未绑定或不可用边界。
- POND-062 增加可复现的高风险水产演示样例：溶氧下行预警、鱼群活动识别、三项指标和置信度。
- 默认仅加载同源媒体；跨域只允许环境变量白名单内的 HTTPS origin，并拒绝 `blob:`、协议相对地址、带凭据 URL 和混合内容，媒体使用 `no-referrer`。
- `useFarmclawBridge.js` 接收 `twin_observation` / `camera_observation` 消息；按 `twin_id` 更新页面状态，地图弹窗无需刷新即可更新。
- 收紧 `LIVE` 语义：媒体来源可信、摄像头在线或识别异常、观测时间在两分钟内且画面实际播放后才显示；断流、网关断开、状态离线或时间过期立即降级。
- 网关观测改为受限字段的 patch / snapshot 合并，支持清除预警、媒体、识别结论和指标；限制对象编号、文本长度与 200 条缓存上限。
- POND-062 继续作为唯一明确演示样例；其他未绑定对象不再生成虚构相机编号、置信度或识别指标。
- 桌面端使用可滚动的窄信息卡；移动端打开对象观测时隐藏后方分析面板与地图工具，并保留顶部状态、底部专题和指令栏。

## 数据边界

- 当前仓库没有真实 RTSP/GB28181/HLS 地址，默认画面为演示识别，不代表现场实时视频。
- 生产接入建议由网关完成鉴权、签名、转码、隐私遮挡和时间戳校准；前端只做观测展示，不提供远程控制。
- 稳定主键为 `twin_id`；媒体字段为 `camera.stream_url` 或 `camera.snapshot_url`。
