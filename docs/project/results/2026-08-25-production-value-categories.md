# 产值预测分类展示成果

日期：2026-08-25

## 交付内容

- 建立“产业 → 品类”两级预测分类，覆盖种植业、水产养殖和未分类。
- 种植业支持番石榴、香蕉、葡萄、火龙果、红薯；水产支持草鱼、鲢鱼、河蟹、虾、鲈鱼。
- 面板展示综合预测指数、预测点、高潜力点、当前筛选数、品类占比与相对全场表现。
- 产业和品类点击会同步更新 MapLibre 预测点过滤，再次点击品类可取消品类过滤。
- 切换到其他专题再返回产值预测时，面板与地图会一致复位为全部 158 个预测点。
- 桌面端使用专业分析面板，390×900 移动端使用 55vh 底部工作面板并隐藏会重叠的地图工具。
- 移动端保留可见的“不代表销售额、利润或真实财务收入”声明。

## 分类结果

- 总预测点：158。
- 种植业：83；水产养殖：72；未分类：3。
- 综合预测指数：80.1；高潜力点：31。
- 归类先判断农田/鱼塘面域，再匹配同产业最近品类；面域外仅在 150 米内匹配，否则保留未分类。

## 数据语义

- 原始数据只有无量纲 `value`，界面统一表述为“演示预测指数”。
- 高潜力为指数 ≥95，稳定为 80–94，关注为 <80；这些是演示分层规则。
- 预测指数不代表销售额、利润或真实财务收入。

## 验证证据

- `npm run test:value`：分类守恒、品类唯一性、指数分层与近邻限制通过。
- `npm run test:ai` 与 `npm run test:security`：通过。
- `npm run build`：通过，仅保留既有大 chunk 提示。
- Playwright：1440×900 与 390×900 下产业/品类切换、当前筛选数、无错误覆盖层、无控制台 warning/error 通过。

## 已知边界

- 当前是基于仓库静态地理数据构建的演示预测，尚未接入市场行情、销售、成本或时序预测模型。
- AMap 兼容模式可展示分类面板，但本轮地图点过滤联动仅实现在默认 MapLibre 模式。
