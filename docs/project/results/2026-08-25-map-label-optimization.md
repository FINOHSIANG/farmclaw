# 地图标注优化成果

日期：2026-08-25

## 交付内容

- 建立“底图信息 → 普通业务 → 异常状态”标注层级，业务文字使用 12–13px Noto Sans、暗色描边、可变锚点和碰撞避让。
- 生产专题从 144 个作物原始点过滤空品类，再与 87 个水产点聚合成 10 个品类标注，显示品类、产业与点位数，避免全量标字。
- 产值专题将 158 个预测点聚合成 11 个品类标注，显示品类、预测指数与样本数，且与产业/品类过滤同步。
- 安防专题为摄像头、电子围栏和园区设施增加名称/状态标注；告警、离线和维护使用文字与语义色双重表达。
- 围栏文字使用独立中心锚点 source，解决大多边形在切片中重复放置标签的问题。
- 作物点颜色规则更新为实际的番石榴、香蕉、葡萄、火龙果和红薯，无效/空品类不参与标注。
- 点击服务点、生产/产值标注和安防对象可查看专业暗色详情浮层；产值浮层明确标记为非财务演示指数。

## 验证

- `npm run test:map-labels`：生产 10 类、产值 11 类/158 点、安防 6 种状态映射通过。
- `npm run test:value` 与 `npm run test:security`：通过。
- `npm run build`：通过，仅有既有大 chunk 提示。
- Playwright：1440×900 的生产/安防/产值专题、香蕉 27 点过滤、安防聚焦与浮层，以及 390×900 移动布局通过；控制台 0 error / 0 warning。

## 已知边界

- 当前优化仅覆盖默认 MapLibre 模式，AMap/Loca 兼容路径保持原实现。
- 公共 OpenFreeMap 不承诺 SLA；生产部署仍建议自托管样式、字体和瓦片资源。
