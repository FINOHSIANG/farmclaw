# ADR-0001 使用 Vue 数字孪生地图作为前端基座

日期：2026-08-25
状态：已接受

## 背景

现有 Farmclaw 使用 Svelte 控制面，已经具备实时遥测和业务模块，但缺少地理空间、无人机、3D Tiles 和数字孪生图层。
上游 `digitalFarm` 已实现这些地图能力，且其核心图层依赖 Vue 生命周期和 AMap/Loca/Three.js。

## 决策

- 将 `farmclaw-dashboard` 切换为 Vue 3，并直接承载上游数字农场地图。
- Farmclaw Python 网关与节点保持不变，通过 WebSocket observer 协议把拓扑、RPC 遥测和 AI 消息注入 HUD。
- 地图 Key 仅从环境变量读取；缺失时 HUD 独立可用并展示配置提示。
- 第一阶段保留上游 `gl-layers` 编译产物，后续再评估替换或重写。

## 备选方案

- iframe 微前端：隔离性较好，但造成两套构建、通信和部署入口，不符合“作为本项目基座”的目标。
- 把全部图层重写为 Svelte：长期结构更纯，但首阶段成本与回归风险过高。

## 后果

- 获得地图、农田/水域/作物/风险/产值、无人机、3D Tiles 等基础能力。
- 前端构建体积和 WebGL 运行成本上升。
- 上游未声明许可证，公开分发前必须解决授权问题。
- 上游单体页面和私有 `gl-layers` 编译产物将成为后续模块化与替换重点。
