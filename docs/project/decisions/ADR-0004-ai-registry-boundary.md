# ADR-0004 模型与知识库管理采用前端注册表和服务端接入边界

日期：2026-08-25
状态：已采纳

## 背景

当前 AI 托管是浏览器内可解释规则引擎，PiAgent 也是规则基线。项目没有真实 LLM Provider 路由、服务端密钥管理、Embedding、向量库、文档接入或 RAG 服务。

## 决策

- 首版在 AI 托管内部提供只管理“当前真实能力与未来接入槽位”的本地 registry。
- 只有规则基线和内置有机农业规则包可标记为本地就绪。
- Provider 和向量知识库示例固定为未配置，不能伪激活，也不生成虚假健康或索引指标。
- API Key、模型端点、知识原文与索引任务必须由未来服务端管理；前端只接收脱敏状态。
- 每个新 AI 任务记录引擎、知识来源和配置版本，安全护栏保持独立且不可由配置关闭。

## 后果

- 用户现在可以查看和管理配置边界，并在未来后端接入时沿用稳定的数据模型。
- 当前页面不等于真实 LLM 或 RAG 已接入；实现真实切换需要新增认证、密钥、健康检查、Provider adapter、文档接入和向量检索服务。
