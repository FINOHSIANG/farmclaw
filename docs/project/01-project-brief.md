# Farmclaw 立项说明

创建日期：2026-08-25
状态：已交付（授权与性能事项待后续处理）

## 背景

Farmclaw 已有分布式网关、边缘节点、AI/RPC 与农业遥测原型，但原 Svelte 控制面缺少真实地理空间和三维数字孪生能力。


## 目标

- 建立可接入 Farmclaw 实时协议的数字孪生智慧农场基座。
- 保持后端分布式节点和技能模型可扩展。
- 提供可安装、可构建、可降级的本地开发体验。

## 非目标

- 本阶段不直接用于生产设备控制。
- 本阶段不落地用户权限、生产数据库或云部署。

## 干系人

- 项目所有者与后续 Farmclaw 开发维护者。

## 用户或使用场景

- 农场运营人员在地图场景中观察田块、环境、节点、风险和 AI 事件。
- 开发者通过模拟数据与边缘节点验证技能/RPC 链路。

## 约束

- 不硬编码密钥、凭证或敏感 URL。
- 保持现有 Python 网关协议兼容。
- 上游未声明许可证，分发边界需等待授权确认。

## 验收标准

- dashboard 使用 digitalFarm 地图/三维场景作为视觉基座。
- Farmclaw 拓扑、遥测、事件和 AI 指令可通过 WebSocket 控制面接入。
- 前端可生产构建，Python 离线测试通过。
- 缺少地图 Key 时显示明确降级提示。

## 风险

- 上游许可不明确；`gl-layers` 源仓库不可公开访问。
- 地图依赖外部 AMap/Loca 脚本，离线不可用。
- 3D Tiles/模型/纹理约 17MB，低端设备有性能风险。

## 验证策略

- 固定上游提交，运行前端生产构建与 Python 测试。
- 检查密钥硬编码和 WebSocket 协议映射。
- 由独立 verifier 审查当前 diff 和已知风险。
